# 103: 2D コンター表示の改善 — カラーマップ選択・手動レンジ・クリックプローブ

## 背景 (ユーザー要望)

1. コンター図のカラーマップのバリエーションを増やしてほしい
2. カラーバーのレンジを変えられるようにしたい
3. クリックした場所の値を拾えるようにしたい

対象は CadCanvas の 2D フィールド描画全般 (静電場 V/|E|、PIC 時間平均/位相アニメ/
ライブ、DSMC ガス場、トレース背景 — `colormap()` と `drawColorbar()` を通る
すべての経路)。フロントエンドのみ。

## 1. カラーマップ選択

### frontend/src/canvas/colormaps.ts (新規)

- 現在 CadCanvas 内にある簡易 viridis (`colormap(t)`) をこのモジュールへ移し、
  以下を追加する。各マップは**アンカー色列 (8〜16点) の線形補間**で実装し、
  256 段の事前計算 LUT (文字列 "rgb(r,g,b)" ではなく [r,g,b] 数値タプル) を
  モジュール初期化時に構築して高速化 (毎フレーム呼ばれるため。理由コメント):
  - `viridis` (既定。従来の見た目とほぼ同じになるようアンカーは matplotlib の
    公known値を使用)
  - `plasma`
  - `inferno`
  - `turbo` (Google の turbo。jet の知覚均一改良版)
  - `jet` (定番。比較用)
  - `coolwarm` (発散型。電位など符号ありの場に有用)
  - `gray` (グレースケール。印刷用)
- API: `COLORMAPS: {key, label}[]`、`sampleColormap(key, t) -> [r,g,b]`、
  `colormapCss(key, t) -> string`。t は [0,1] クランプ。
- アンカー値は matplotlib / turbo 論文の代表色を 8〜16 点で近似 (厳密一致は不要、
  見た目が崩れないこと)。

### UI

- キャンバスツールバーの表示トグル群の並びに「配色」select を追加
  (フィールド表示が有効なときだけ表示)。選択は App の UI state
  (`colormapKey`, project へは保存しない)。全フィールド描画経路 + カラーバーの
  グラデーションに適用。

## 2. カラーバーの手動レンジ

- App に UI state `colorRange: { min: number | null, max: number | null }`
  (null = 自動 = 従来挙動)。
- ツールバー配色 select の隣に min/max の CommitNullableNumberInput (空欄=自動) と
  「自動」リセットボタン。プレースホルダに現在の自動値を表示できると良い
  (可能なら。難しければ省略可)。
- 描画側: 手動値があれば正規化 t の分母/分子に使い、**範囲外は端色にクランプ**。
  対数表示中は log10(min/max) に適用 (min ≤ 0 なら従来の最小正値フォールバック)。
  カラーバーのラベルも手動値を反映。
- 位相アニメの「スケール固定」機構 (fixedScale 相当) と併存: 手動レンジ指定が
  最優先、次に fixedScale、最後に自動 (優先順位をコメントに)。

## 3. クリックプローブ

- 新ツール「プローブ」(Tool union に "probe")。フィールド表示中のみボタン活性。
- クリックで、その位置のフィールド値を読み取り:
  - 節点ベースの場: 所属三角形の重心座標で線形補間
  - 要素ベースの場: 所属要素の値
  - 所属三角形の探索は sheath.ts の総当たり探索 (点位置特定) を流用/共通化
  - ドメイン外クリック: 「ドメイン外です」表示
- 表示: クリック点に十字マーカー + 近傍に小さな読み取りボックス
  (座標 (表示単位) と値 (フィールドの単位、formatNumber))。最後のクリック
  1点のみ保持 (新クリックで置換)。ツールを離れるかフィールド表示を切り替えたら
  消える。Esc でも消える (既存ツールの Esc 流儀に合わせる)。
- 位相アニメ中は現在ビンの値を読む (ビン切替で値を再評価して表示更新)。
- 1D (Plot1dView) は対象外 (チャートで値が読めるため。今回はスコープ外)。
