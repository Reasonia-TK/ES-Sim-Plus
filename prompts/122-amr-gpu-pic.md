# 122: v2 AMR P4b — 合成格子の GPU 求解・AMR 上の PIC・解に基づく適応細分化

計画書: `prompts/119-v2-rebuild-plan.md` (P4)。前段: `prompts/121-amr.md` (P4a、静電場の合成格子)。

## 目的

1. 合成格子 (A_c = PᵀAP) を GPU で解く (静電場の高速化と、PIC の毎ステップ求解のため)
2. GPU PIC-MCC を AMR 階層の上で動かす (電極の細部・狭いギャップ・シース近傍だけ細かくする。
   v1 で局所細分化メッシュ + PIC を使っていた用途の置き換え)
3. 静電場の解に基づく適応細分化 (境界近傍・指定矩形に加えて、誤差の大きい所を自動で細分化)

## 1. GPU AMG-PCG (es_sim/amr/gpu_solver.py、kernels/amr.cu)

- 階層は CPU の pyamg (smoothed aggregation、symmetric、max_coarse≈500) で作り、各レベルの
  A_l・P_l・R_l = P_lᵀ を GPU の CSR (int32 添字) に載せる。最粗レベルは密な逆行列
  (特異なら擬似逆行列) の GEMV。
- 平滑化は **対称 Chebyshev (D⁻¹A、3 次)**。固有値の上限は冪乗法 × 1.1、下限は上限/30。
  pyamg 既定の Gauss-Seidel は GPU で並列化できず、pyamg の chebyshev は前処理が不定に
  なった (CG が破綻)。自前の Chebyshev は Jacobi 2 回より反復が少ない (試作: 同軸 L2 で
  CG 10 反復 vs 11、細線 L3 で 11 vs 13)。前・後平滑化を同じ多項式にして V サイクルを対称に。
- CG は既存の同期なしカーネル (poisson.cu の dot_acc・pcg_xr・pcg_p) を使う。PIC 用の
  launch_solve は固定反復・warm start・CUDA Graph に取り込み可能 (実行中に確保しない)。
  静電場用の solve は反復ごとに残差を見る。未知数 ≤ 4096 は密な逆行列で直接解く。
- Dirichlet の無い問題 (特異) は右辺を平均 0 に射影し、解の平均を 0 にする。

## 2. AMR 上の GPU PIC

### 節点と解の流れ (1 ステップ)

全節点 (合成格子の正準節点: 未知・ぶら下がり・固定) を 1 本の配列で持つ。
1. 粒子の電荷を葉セルの 4 隅へ CIC で堆積 (q_all)。ぶら下がり節点に載った分は Pᵀ で親へ
2. b_c = Pᵀ q_U + Coup_c V(t) → AMG-PCG → φ_c
3. φ_all = P_node φ_c + C_node V (固定節点は C_node の行が自分のグループの単位ベクトル)
4. 節点電場 E_all = G φ_all + D V (後述の CSR ステンシル)
5. 粒子位置の葉セルで E を双一次補間 (CIC) → プッシュ

細分化が無いとき (L=0) は現行の一様格子 PIC と同じ離散化になる (回帰テスト)。

### 粒子の所属セル (O(レベル数))

各レベルのブロック表 (refined: そのブロックが細分化されているか、blockid: 領域内ブロックの
番号) をブロック解像度の密配列で持ち、レベル 0 から「細分化されていれば 1 段下へ」を
繰り返して葉セルを得る (座標の 2 倍は浮動小数点で厳密なので添字が整合する)。ブロックごとに
(bf+1)² 格子点の節点番号表を持ち、葉セルの 4 隅の節点番号をそこから引く。レベル l の領域内の
格子点は必ず合成格子の節点 (葉セルの角か、より細かいセルの角) になる。

### 節点電場のステンシル G, D (es_sim/amr/fieldops.py)

節点ごとに、その節点を角に持つ最も細かいレベルの格子幅 h で ±h の点の電位を使う中心差分:
- ±h の点が節点ならその値、節点でなければ (粗い側) それを含む葉セルの双一次補間
- 線分 [節点, 節点 ± h] が導体境界と交わるなら、交点までの距離 θh と導体電位の
  ゴーストフルイド差分 (一様格子の es_deriv と同じ式)。外周 Neumann 側は 0、固定節点は
  未知の隣への片側差分の平均 (es_deriv と同じ)
- 結果を疎行列 E_x = G_x φ_all + D_x V (D はゴーストの導体電位の係数) に組み、GPU で SpMV

### 粗細界面の自己力

運動量保存型 (節点電場 + CIC 補間) は一様格子では自己力 0 だが、粗細界面では粒子自身の
場が 0 にならない (WarpX/Vay の MR では界面近傍の粒子を粗いレベルで扱う緩衝帯で抑える)。
大きさを 1 粒子の数値実験で測り、一様な熱プラズマが細分化領域の内外で一様なまま保たれる
ことをテストで確かめる。問題があれば緩衝帯 (界面から n セル以内は粗いレベルで補間) を入れる。

### 診断

時間平均の密度・Te・電離率・位相分解は全節点の配列に積み、節点の双対体積 (葉セルの四分体の
気体体積の和、軸対称は r 重み・2π) で割る。フレームの要素密度は葉セルごとのヒストグラム。
場のエネルギーは合成格子の辺リスト (energy_and_charges と同じ式)。表示は AMR の表示用メッシュ。

## 3. 解に基づく適応細分化 (静電場)

`mesh.amr.adaptive`: 求解 → 誤差指標 → タグ → 階層の作り直し、を最大 adapt_iters 回。
指標は節点の二階差分 η = max(|φ(x+h) − 2φ + φ(x−h)|, y 方向) (≈ 8 × 双一次補間誤差) で、
η > adapt_tol × (電位の範囲) の節点を含む葉セルを 1 段細かくする (max_level まで)。
導体との交差がある差分は除外 (境界近傍は refine_boundaries が担当)。既存の細分化は保つ
(階層は単調に細かくなるだけ)。PIC の動的な再格子化 (λ_D に基づく) は P4c。

## 検証

- GPU AMG-PCG が CPU (pyamg) と一致、反復数、特異問題
- 電場ステンシル: L=0 で一様格子の node_field と一致、線形場で厳密、同軸で 2 次
- AMR PIC: L=0 で一様 PIC と一致、プラズマ振動 2f_pe (細分化あり)、エネルギー保存、
  一様熱プラズマの密度が界面の内外で一様、1 粒子の自己力の大きさ、電荷保存
- 適応細分化: 誤差が許容値以下になる・細線同軸で境界細分化より少ない未知数で同精度

### 粗細界面の自己力 (測定と判断)

1 粒子の自己力 (自分の電荷が作る場を自分が受ける) は、一様格子 (運動量保存型) では 3e-9 で 0 だが、
細分化パッチでは界面上で「同じ粒子が 1 格子幅離れた所に作る電場」の 28%、パッチから 4 セル
離れても 1.8% (パッチへの引力) が残る。原因は合成格子のグリーン関数の非対称
(並進不変性・反対称性が崩れる) で、界面近傍の粒子を粗いレベルで扱う緩衝帯 (WarpX/Vay の
gather/deposition buffer) では減らなかった (試験: 緩衝 1〜4 セルで最大値 0.28 のまま)。
自己力による電位は 1 粒子あたり ~0.1·w·e/(2πε0) (w = マクロ粒子の重み [1/m]) で、PIC の
粒子ノイズ (粒状性) と同程度。熱平衡プラズマの試験で密度への影響は検出できない (< 0.1%)。
粒子数が極端に少なく冷たい種 (イオン) が界面近傍に長く留まる条件では注意。必要になれば
界面近傍のセルだけ自己場の 4×4 ブロックを事前計算して差し引く補正 (Colella–Norgaard 型) を P4c で。

### 回帰で見つかった既存バグ (一様格子の GPU PIC、同時に修正)

- 周期境界の従属節点 (右端・上端) の表示密度が 0 だった (堆積は主節点に巻き戻すため)
- 周期境界で初期のマクロ粒子の重みが従属節点の体積を二重に数えて 3% 大きかった (64 セルで 65²/64²)
- 全周期 (特異) で密な直接法の擬似逆行列を SVD で求めて 4096 元で ~24 s かかっていた
  → 零空間 (定数) を持ち上げた逆行列 A⁺ = (A + α uuᵀ)⁻¹ − uuᵀ/α (~1 s)
