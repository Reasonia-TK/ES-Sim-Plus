# 121: v2 AMR (ブロック構造の局所細分化) — 静電場の合成格子ソルバー (P4a)

計画書: `prompts/119-v2-rebuild-plan.md` (P4)。参照: AMReX (AmrCore の tagging/regrid、
blocking_factor・proper nesting、MLMG の合成格子解法)。

## 目的

直交格子 + 埋め込み境界 (EB) エンジンに、電極・誘電体の近傍やユーザー指定領域だけを
2 倍ずつ細かくする局所細分化を入れる。一様格子で同じ精度を得るより大幅に少ない未知数で、
曲面電極の近傍場・狭いギャップ・シース近傍を解像することが目的 (「メッシュ機能向上」の本丸)。
P4a は静電場 (/solve・/profile) まで。PIC (P4b) と流体 (P4c) は同じ合成格子の上に載せる。

## 階層 (AMReX と同じ考え方)

- レベル 0 は現行の一様格子 (domain 全体、セル数 m·2^k)。レベル l の格子幅は h/2^l。
- 各レベルの領域は **ブロック** (blocking_factor × blocking_factor セル、既定 8) の和集合。
  細分化の単位をブロックにすることで AMReX の blocking_factor と同じくパッチが揃い、
  後の GPU カーネル (P4b) がブロック単位で書ける。
- **proper nesting**: レベル l+1 の領域は、レベル l の領域の内側にレベル l のブロック 1 個分の
  緩衝帯を持って収まる (domain 外周に接する所は除く)。これにより隣接する葉セルのレベル差は
  高々 1 (2:1 バランス) になる。
- タグ付け: (a) 導体・誘電体の境界から buffer セル以内のセル、(b) ユーザー指定の矩形領域
  (目標レベル付き)、(c) 適応 (P4b 以降: 解の勾配・λ_D/h)。タグの付いたセルを含むブロックを
  細分化し、細かいレベルから粗いレベルへ proper nesting を満たすよう領域を広げる。

## 合成格子の離散化 (保存・対称を構成で保証する)

現行の節点中心 FV の演算子は「セルごとの寄与の和」に分解できる: 辺 (P,Q) のコンダクタンス =
その辺を挟む 2 セルの半チューブの和。そこで:

1. **葉セル** (そのレベルの領域内で、より細かいレベルに覆われていないセル) ごとに、4 辺
   それぞれの半チューブのコンダクタンス (誘電体の直列/並列合成・導体のゴーストフルイド θ を含む)
   を現行と同じ規則で求め、角の節点間の結合として全体行列 A_full に加える。
   節点は最細レベルの添字空間の座標で同定する (粗い節点は同じ位置の細かい節点と同一)。
2. **ぶら下がり節点** (細かい領域の境界上で、粗い葉セルの辺の中点にある節点) は、その粗い辺の
   両端の値で φ_h = w_a φ_a + w_b φ_b (w_a + w_b = 1) と拘束する。拘束を行列 P (と固定節点の
   寄与 C) で表し、**A_c = Pᵀ A_full P**、右辺 b_c = Pᵀ(b_full + Coup_full·V − A_full C V) とする。
   Pᵀ A P は A が対称正定値なら対称正定値、Pᵀ による右辺の集約は電荷・フラックスを保存する
   (有限要素のぶら下がり節点消去と同じ構成)。
   - **重み** (実装時の知見): Pᵀ は同じ重みでぶら下がり節点の方程式 (細かい側から入る流束) を
     端点へ配る。その流束の通る面 (ぶら下がり節点に細かい側から接する 2 本の半チューブ) は、
     粗い側の双対セルの境目 (辺の中点) で a 側と b 側に分かれる。そこで重みを 2 本の半チューブの
     ∫ε dA (軸対称は r 重み) の比 w_a = A_a/(A_a + A_b) にする。一様な直交座標では線形補間
     (½) に一致し、軸対称の径方向の辺では ½ − h/(8 r_m)、誘電体界面上では ε 比になる。
   - 線形補間 (½) のままだと、界面に平行な一様場の流束収支が合わない所が出る:
     軸対称で軸 (r=0) に接する界面では軸上の節点に O(h) の誤差 (厳密解 z(Z−z) で 1 次収束、
     同心球で軸上に誤差の山)、誘電体界面がぶら下がり節点を通ると φ = 1000x が 0.3 V ずれる。
     面積比の重みでどちらも解消 (2 次収束・丸め誤差で厳密)。
   - 電極電荷は Dirichlet 結合の流束に、端点が電極のぶら下がり節点の拘束反力 Cᵀr
     (r = A_full φ_U − Coup·V − q) を加える。これで Q_k = ∂W/∂V_k となり、ΣQ = −Σq と
     2W = Σ Q_k V_k が厳密に成り立つ。
3. 一様格子 (細分化なし) では合成格子の行列は現行の build_level と一致する (テストで確認)。
4. 右辺: 静的電荷 ∫ρ dV は葉セルの四分体ごとに角の節点へ加え、Pᵀ で集約する。
5. 求解: A_c は疎行列で陽に組み、CG + 代数マルチグリッド (pyamg の smoothed aggregation) で
   解く (P4a は CPU。GPU は P4b で cupyx の CSR に移す)。

## 出力

- 各レベルの節点値 (レベル領域内は合成格子の解、領域外は粗いレベルから双一次補間)、
  電場はレベルごとに現行と同じ節点差分。
- v1 UI 互換の表示用メッシュ: 全レベルの葉セルを 2 三角形に分割 (ぶら下がり節点は拘束値を
  持つので粗いセルの三角形と値が連続し、表示に割れ目が出ない)。
- 容量・エネルギー・電極電荷は合成格子の二次形式とフラックスから (現行と同じ定義)。

## スキーマ

`MeshSettings.amr: AmrSettings | None` (None = 細分化なし、cartesian モードのみ有効):
`max_level` (0〜4)、`refine_boundaries` (bool、導体・誘電体の境界近傍を最大レベルまで)、
`buffer_cells` (境界からのセル数)、`blocking_factor` (4/8/16)、`regions` ([{p1, p2, level}])。

## 検証 (tests/test_v2_amr.py)

1. 細分化なし = 現行の一様 EB ソルバー (φ が丸め誤差で一致)
2. 平行平板 + 細分化領域: 線形解を丸め誤差で再現 (粗細界面の整合)
3. A_c の対称性、Pᵀ による右辺の総電荷保存
4. 同軸円筒で内導体近傍を細分化: 同じ最細格子幅の一様格子とほぼ同じ精度を、はるかに少ない
   未知数で得る。細分化レベルを上げると誤差が 2 次で減る
5. 誘電体円柱 (界面近傍を細分化) の内部電場が解析解に近づく
6. proper nesting・2:1 バランスがどの入力でも成り立つ

## 実装 (2026-09-29)

- `es_sim/amr/hierarchy.py` (AmrSpec・AmrHierarchy)、`composite.py` (合成格子の組立・
  AMG-CG・エネルギー/電荷)、`electrostatic.py` (solve_electrostatic_amr・表示用メッシュ・
  任意点の標本化)。`field/compat.py` が mesh.amr で細分化が起きるときだけ AMR 経路へ振り分け
  (タグが無ければ一様格子の GMG-PCG = GPU 可)。依存に pyamg を追加。
- UI: メッシュ欄 (直交格子モード) に AMR 設定 (最大レベル・境界近傍の細分化・緩衝セル・
  ブロック・細分化矩形の一覧)、ツリーのメッシュ行に「AMR L*」。PIC は基本格子で計算し警告。

## 検証結果

| 項目 | 結果 |
|---|---|
| 細分化なし vs 一様 (同軸 64²) | φ 差 6.7e-9、容量一致 |
| 全域をレベル 2 vs 一様 128² | φ 差 < 1e-7、容量一致 |
| 平板 + 細分化矩形 (線形解) | 誤差 9e-9 V、ぶら下がり節点 180 |
| 空間電荷の二次式 (直交, 界面あり) | 誤差比 3.9〜4.0 (2 次) |
| 軸に接する界面 (RZ, z(Z−z)) | 面積比の重み: 比 4.0 (2 次)。線形補間: 比 ≈ 2 (1 次) |
| 電場に平行な誘電体層が界面を横切る | 面積比の重み: 3e-9 V。線形補間: 0.28 V |
| 細線同軸 a=1mm (矩形 ±4mm を L3) | 未知数 11,000 で最大誤差 4.3e-4 (一様 512² = 26 万節点で 4.2e-4) |
| 同心球 RZ (境界細分化, 基本 L/32) | 最大誤差 L1 1.6e-3 → L2 8.9e-4 → L3 3.0e-4 |
| 電荷保存・エネルギー | ΣQ/Q ~ 1e-10、2W = ΣQV (相対 5e-15) |

境界近傍だけを細分化した太い同軸 (a=10mm) では容量誤差が ~1e-4 で頭打ちになるが、これは
細分化しない中間部の粗い格子の誤差 (界面の不整合ではない)。解の曲率に応じた適応タグ付けは P4b。
