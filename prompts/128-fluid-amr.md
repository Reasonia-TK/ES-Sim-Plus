# 128: v2 P5e — 流体 2D の AMR 対応 (合成格子の Voronoi 有限体積)

計画書: `prompts/119-v2-rebuild-plan.md` (P5)。前段: `prompts/125-cartesian-fluid.md` (直交格子 + EB 版)、
`prompts/126-gpu-fluid.md` (GPU 版)、`prompts/121-amr.md`・`122-amr-gpu-pic.md` (合成格子の Poisson)。

## 目的

流体 2D の直交格子版は一様格子だけで、`mesh.amr` を指定しても基本格子で解いていた (警告)。シースや
固体のまわりだけ細かい格子で、全体を細かくした一様格子と同じ結果を少ない未知数で得る。

## 離散化 (es_sim/gfluid/amr_graph.py)

- 合成格子の全節点 (ぶら下がり節点を含む) を輸送の未知数とし、葉セルの **Delaunay 適合三角形分割の
  Voronoi 有限体積** で輸送グラフ (節点体積・辺の重み w_ij = Voronoi 面の長さ / 辺長) を組む。
  - 細分化の境目に接しない葉セルは対角線で 2 つの直角三角形に分ける。直角三角形の外心は斜辺の中点
    なので Voronoi 領域は双対セル、斜辺の重みは 0 — 一様格子版 (gfluid.geometry) と同じ離散化になる。
  - 辺の中点にぶら下がり節点を持つ粗い葉セル (遷移セル) は角と中点の Delaunay 三角形分割
    (16 通りを前計算)。すべて鈍角の無い三角形なので重みは非負で、行列は常に M 行列。
  - SG (EAFE) の流束・壁・反応・時間積分は一様格子版と共通 (FluidGraph の形が同じ)。
- 固体は一様格子版と同じ埋め込み境界: 境界が通る葉セルの三角形では、Voronoi 領域の気体の割合を
  標本点で、Voronoi 面の開口を「辺に平行な標本線が端から端まで気体中を通るか」で求める。固体内部の
  節点にかかる気体の小片と壁は隣のアクティブ節点へ併合 (グラフの隣接で 1〜2 つ先まで)、固体表面は
  小片に分けて最寄りの節点に持たせる。軸対称は r 重み (Voronoi 面は ∫ r ds、領域は ∫ r dA)。
- 壁向きの電場 E·n: 壁上の点 W と、法線の逆向きに局所の格子幅 1 つ分入った点 A の電位差
  (φ は合成格子の葉セルでの双一次補間)。
- Poisson: P4 の合成格子の演算子 (`build_pic_layout` の PTq / PC)。電荷は節点の気体体積 ×
  e(n_i − n_e) を Pᵀ で未知へ集約、電位は PC で全節点 (ぶら下がり節点は補間) に戻す。CPU は未知数
  6 万以下なら疎行列 LU (前分解)、それより大きいか特異なら pyamg の AMG-CG。
- 表示用メッシュ = 適合三角形分割 (導体内部の葉セルを除く)。/ws/fluid2d の started とバッチの bundle に載る。

## 実装

- `gfluid/amr.py`: `AmrFluid2dSimulation(CartesianFluid2dSimulation)` (輸送グラフの構築と Poisson だけを
  差し替え)、`GpuAmrFluid2dSimulation(GpuCartesianFluid2dSimulation, AmrFluid2dSimulation)` (輸送は
  gfluid.gpu のカーネルそのまま、Poisson は GPU の AMG-PCG: `gpu._AmrPoisson`。未知数 4096 以下は
  密な逆行列、それより大きいと同期なしで k 反復ずつ積む)。細分化は mesh.amr の静的な指定 (導体・
  誘電体の境界近傍・指定矩形)。`adaptive` は使わない (警告)。
- 一様格子版の `_init_geometry` を `_build_graph` (輸送グラフ・表示用メッシュ・Poisson の前処理) と
  `_adopt_graph` に分け、AMR 版は `_build_graph`・`_init_poisson`・`_solve_phi` だけを上書きする。
  GPU 版の Poisson は `_EbPoisson` (一様格子の GMG) / `_AmrPoisson` の 2 実装に分けた。
- 振り分け (`make_fluid2d_simulation`): mesh.amr で実際に細分化が起きるなら AMR 版 (起きなければ
  一様格子版)。GPU 版を選ぶ条件は一様格子版と同じ (AMR は葉セル数で未知数を見積もる)。

## 付随して直したこと

- 固体の表面上の節点から出る辺の開口: 標本線の端点が丸め誤差で固体側 (例: 0.011999… < 0.012) に
  入ると、`_lines_all_gas` が長さ ~1e-18 の区間を固体と数えて開口を半分にしていた。格子に揃った
  誘電体ブロックの表面の 3 本の辺が半開きになり、電子密度が細かい一様格子より 12% 高くなっていた。
  標本線の両端を eps (= 1e-6 × 最細の格子幅) だけ内側に縮めて解消。一様格子版は同じ条件で影響なし
  (格子に揃った面の辺がすべて全開であることを 5 通りの配置で確認)。
- 直角三角形の斜辺の重み (本来 0) に丸め誤差の正の値 (~3e-16) が残って輸送の辺に入っていたのを除いた。

## 検証 (tests/test_v2_gfluid_amr.py、GPU は tests/test_v2_gfluid_gpu.py)

| 項目 | 結果 |
|---|---|
| 輸送グラフの幾何 (格子に揃わない円の導体 + 多角形の誘電体、L1・L2) | 気体体積 1.3e-4 (L1)・2.1e-5 (L2)、節点体積の和 = 気体体積 (機械精度)、併合の取りこぼし 0、壁面積は解析値に 1e-9、重みはすべて正 |
| 線形場の整合性 (ぶら下がり節点を含む内部の節点) | Σ w_ij (x_j − x_i) = 0 が 6e-13 (Voronoi 領域が閉じている) |
| 細分化域と同じ幅の一様格子 (格子に揃った固体) | 節点体積・辺の重み・壁が節点ごとに一致 (上記の丸めの不具合はこのテストで検出される) |
| 軸対称 (rz / rz_x0、軸上に誘電体) | 体積 π R² L・壁面積が厳密 |
| Poisson (同じ空間電荷) | 細かい一様格子との差 0.034 V (最大電位の 0.08%)、粗い一様格子 0.075 V |
| 粒子収支 (ぶら下がり節点・固体の併合込み) | 全量変化 = 生成 − 壁損失 (1e-8) |
| Boltzmann 平衡 (イオン固定・反射壁・細分化の境目をまたぐ) | n_e ∝ exp(φ/Te) が 0.02 以内 |
| 固体入り CCP 800 ステップ (0.5 mm + L1 vs 一様 0.25 mm) | 電子数 0.2% (粗い一様格子 1.0%)、イオン壁損失 1.6% (4.7%)、生成 0.3% (1.7%)。時間平均の n_e・n_i・Te は 3% 以内 |
| 誘電体ブロックのみ 1500 ステップ | 電子数 0.09% (粗い一様格子 2.3%、修正前の AMR は +12%) |
| GPU 版 | CPU の AMR 版と 1e-9 (密な直接法)・1e-8 (AMG-PCG)、BiCGSTAB の反復数も同じ。特異な Poisson も一致 |
| 振り分け・/ws/fluid2d・バッチ | AMR 版を選び、表示用メッシュ (適合三角形分割) と場の長さが合う |
