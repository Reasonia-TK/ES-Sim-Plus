# 134: 自己バイアス (阻止コンデンサ) (計画)

依頼 (2026-10-02): GEC 基準セルのサンプル (`examples/gec_cell.json`) を追加したところ、RF 電極が電源に直結で
阻止コンデンサが無く、自己バイアスが付かないことが分かった (時間平均のプラズマ電位が約 80 V。実機は RF 電極に
大きな負の直流バイアスが付く)。自己バイアスに対応する。

決めたこと (2026-10-02):

- PIC は後回しにして、流体 (1D・2D) から対応する。
- 阻止コンデンサの容量は文献で決める (下の「阻止コンデンサの容量」)。
- 流体 (SB-a〜SB-d) のあと PIC に進む (依頼 2026-10-02)。計画は下の「PIC」。

## 目的

- 電極と電源の間に直列の阻止コンデンサ C_b を置けるようにし、電極の直流電位 (自己バイアス) が放電に合わせて
  自己無撞着に決まるようにする。
- 実機 (GEC セル) の自己バイアスと比べられるようにする。

## 今の形 (調査の結果、2026-10-02)

- どのエンジンも電極は電源に直結 (Dirichlet の電位 = V(t) = voltage + ΣRF + 波形)。回路や浮いた電極の仕組みは
  無い。電極の電荷を求めているのは静電場 (/solve) だけ。
- 1 つの境界条件に複数の辺を指定すると、辺ごとに別の Dirichlet グループになる (`geom/model.py`)。コンデンサは
  「電極 = グループの集まり」を 1 つの回路の節点として扱う。

| エンジン | 電極の電位を決める所 | 電極ごとの伝導電流 | 電極の電荷 | 難しさ |
|---|---|---|---|---|
| 流体 1D (`fluid1d.py`) | `_solve_phi` の両端 (`electrode_voltage`) | 左右の壁流束 (`gwl_*`・`gwr_*`) がある | 端のセルの電束から | 易 |
| v2 流体 2D CPU (`gfluid/simulation.py`。時間積分は v1 の `fluid2d.py` を継承) | `_solve_phi` の `group_voltages` | 導体の壁の小片は `wall_group` がある。外周の辺の小片は −1 | 静電場と同じ ΣG(V − φ) | 易〜中 |
| v2 流体 2D GPU (`gfluid/gpu.py`) | サブステップごとにホストで `vgrp` に入れる | 節点ごとの `gwi`・`gwe` がある | デバイスで集約が要る | 中 |

## 物理のモデル

Vahedi & DiPeso (J. Comput. Phys. 131, 149 (1997)) の「電位と回路の同時解」を、回路が阻止コンデンサだけの場合に
使う。

- 電極の節点 N (電極の導体 + コンデンサの電極側の板) の電荷 Q_N は、伝導電流 (イオン・電子の壁流束、二次電子)
  でだけ変わる: dQ_N/dt = I_cond。
- Q_N = Q_e + C_b (V_e − V_s)。Q_e は電極の表面の電荷、V_e は電極の電位、V_s は電源の電圧 (今の
  voltage + ΣRF + 波形)。
- Q_e は V_e について線形: Q_e = Q_e0 + C V_e。C は電極の自己容量 (コンデンサの電極が複数なら容量行列)、Q_e0 は
  空間電荷とほかの電極の電位で決まる。
- よって (C + C_b) V_e = Q_N − Q_e0 + C_b V_s。
- 1 サブステップの手順 (Poisson は今までどおり 1 回):
  1. 前の V_e で φ* を解く。
  2. 電極の電荷 Q_e* を求め、Q_e0 = Q_e* − C V_e^old。
  3. 上の式で新しい V_e。
  4. φ = φ* + (V_e − V_e^old) ψ。ψ は「その電極 1 V・ほかの電極 0 V・空間電荷 0」の解で、最初に 1 回だけ
     解く。C も ψ から求める。
  5. 輸送のあと Q_N += I_cond Δt。
- 電極の電荷は離散の Gauss の法則と合う形にする: 電極から領域への電束から、電極の節点 (Dirichlet 節点) に
  置かれた空間電荷を引く。引かないと、壁の節点の電荷が電極へ流れ込んだときに V_e が跳ぶ (その電荷は前から
  壁の位置にあり、電場は変わらないので、跳ぶのは誤り)。
- 初期: V_e(0) = V_s(0) + initial_bias_v (コンデンサの初期電圧) になるよう Q_N を置く。
- 極限: C_b → ∞ で直結 (+ 一定のずれ) に一致する。定常の直流分は「1 周期の正味の伝導電流 0」で決まり、
  C_b ≫ C (電極の容量 + シースの容量) なら C_b によらない。C_b が決めるのは、落ち着くまでの時間
  (≈ R_eff·C_b、R_eff ≈ Te/I_i) と RF の分圧 (≈ C/C_b) の 2 つ。
- 単位: 電荷・容量は座標系の単位で、今の静電場の電荷と同じ。軸対称は C・F、平面 2D は奥行き 1 m あたりの
  C/m・F/m、1D は面積あたりの C/m²・F/m²。

GEC サンプルでの見積もり:

- 電極の自己容量 C = 33.6 pF (真空、静電場で計算)。シースの容量は 10〜25 pF 程度。
- RF の分圧: 5 nF で約 1%、0.1 µF で 0.05%。
- 落ち着くまでの時間: R_eff ≈ Te/I_i ≈ 300〜1000 Ω として、5 nF で 1.5〜5 µs (20〜70 周期)、0.1 µF で
  30〜100 µs (400〜1400 周期)。

決定:

- GEC サンプルは **5 nF** (GEC セルの 2D シミュレーションの文献値)。実機の 0.1 µF でも定常の自己バイアスは同じ
  (C_b ≫ C のため) で、落ち着くまでに約 20 倍かかる。SB-b で両方が同じ所へ向かうことを確かめる。
- UI でコンデンサを付けたときの既定値は、軸対称で 5 nF。平面 2D は 5×10⁻⁸ F/m (奥行き 10 cm で 5 nF)。1D は
  6×10⁻⁷ F/m² (GEC の電極 (直径 101.6 mm) の面積あたり 5 nF)。目安として「電極の容量の 100 倍以上」と書き、実行後に
  電極の容量 C と RF の分圧を出す。

## 文書 (スキーマ) と UI

- `BlockingCapacitor {capacitance (> 0、座標系の単位), initial_bias_v (V、既定 0)}`。`Region` (導体)・
  `BoundaryCondition` (dirichlet)・`Pic1dElectrode` (流体 1D・PIC 1D が使う) に
  `blocking_capacitor: BlockingCapacitor | None` を足す。None なら今までどおり直結。
- コンデンサを付けた電極の voltage (直流分) は、定常では効かない (コンデンサが止める)。UI に注意を出す。
- 静電場 (/solve) はコンデンサを無視する (直流分 voltage のまま)。
- 未対応のエンジン (PIC) で使うと、実行の初めにエラーにする (黙って直結で計算すると物理が違うため)。SB-f で
  全てのエンジンが対応したので、このエラーは無くなった。
- 結果 `circuit`: 電極ごとに次を返す。フレームには今の V_e と V_dc を載せる。
  - label・容量・電極の容量 C
  - RF 1 周期ごとの V_dc (電極の電位の平均)・|V1| (電極の電位の基本波の振幅)・正味の伝導電流
  - 最後の 1 周期の V_e(t)
- UI:
  - エディタ (導体・Dirichlet の辺・1D の電極) に「阻止コンデンサ (自己バイアス)」の欄。
  - 実行のページに、数値サマリの自己バイアス・|V1|・比、V_dc の推移のグラフ、RF 波形モニタの実際の電極の電位。
  - スイープの候補 (容量・初期バイアス) と集計 (V_dc)。
- 「続き」: コンデンサの電荷はシミュレーションの中に持ち、そのまま引き継ぐ。

## エンジンへの組み込み

### 共通 (`es_sim/circuit.py`)

- 回路の節点の状態 (Q_N・V_e) と、新しい V_e を求める小さな連立方程式。
- RF 1 周期ごとの集計 (V_dc・|V1|・I_dc)。サブステップの区間の積分を、周期の境で分けて足す。
- 結果とフレームの形。エンジンからは ψ と C、Q_e*、I_cond を受け取る。

### 流体 1D

- ψ は直線 (左は 1 − x/L、右は x/L)、C = ε0/L (面積あたり)。両方の電極に付ければ 2×2 の行列。
- Q_e* (左) = ε0(φ0 − φ1)/dx − e(n_i − n_e)_0·dx/2。右も同様。
- I_cond = e(Γ_i − Γ_e) (壁への正味の流束。Γ_e は入射から二次電子を引いたもので、今の `gwl_e`)。

### v2 流体 2D (CPU)

- 壁の小片ごとに「電荷の行き先の電極」を持たせる。行き先は次の 3 つ。
  - 導体の表面: 今の `wall_group`
  - 外周の Dirichlet の辺: その辺のグループ (今は −1)
  - 電極に接した誘電体の縁 (Poisson の固定節点): 今も電極へ流れる扱い
- ψ は LU (前分解を再利用) か GMG で 1 回解く。C は ψ の電束から求める。
- Q_e* = Σ G_Pk (V_k − φ_P) − (電極の固定節点の電荷)。軸対称は 2π を掛ける。
- v1 の `_step_once` の表面電荷の積算と同じ所に、伝導電流の積算のフックを足す (v1 の流体 2D も同じフックを使う)。

### v2 流体 2D (GPU)

- 回路 (`BlockingCircuit`) は CPU 版と同じものをホストに置き、CPU 版と同じ量をデバイスで集約して読む
  (SB-b で決めた。デバイスに回路を写すより単純で、CPU 版と式が 1 つで済む):
  1. コンデンサの電極のグループ電位を前の V_e にする。
  2. Poisson を解く。
  3. 電極の電荷を、電極ごとに 1 ブロックの決定的な集約 (`fl_cap_charge`) で求めて読む。
  4. ホストで新しい V_e を求める。
  5. x += ΔV ψ (`fl_axpy`) のあと、固定節点を埋め直す。
  6. 輸送のあと、伝導電流 (`fl_cap_current`) を読んで Q_N に積む。
- 同期は 1 サブステップに 2 回増える (BiCGSTAB は反復ごとに 1 回読んでいるので、それに比べて小さい)。
- 途中停止の巻き戻し (`_save_step_state`) にコンデンサの状態も入れる。

### AMR の流体 2D・v1 の流体 2D (SB-d)

- AMR: ψ は合成格子で 1 回解く。電荷は合成格子の残差から求める (`amr/composite.py` の `energy_and_charges` と
  同じ形)。流体の AMR は格子が固定なので、作り直しは要らない。
- v1: ψ は K_ff の LU で解き、電荷は K[fixed,:]·φ − f。壁エッジは両端の Dirichlet 節点から電極に帰属させる。

### PIC (SB-e・SB-f。2026-10-02 に計画)

調査の結果 (2026-10-02):

| エンジン | 電極の電位を決める所 | 吸収・放出の電荷 | Poisson |
|---|---|---|---|
| PIC 1D (`pic1d.py`) | `_solve_phi` の両端 (`electrode_voltage`) | 左右の壁を越えた粒子・二次電子・FN が左右別にある | 三重対角 (厳密) |
| v1 PIC (`pic.py`) | `_dirichlet_values` | 越えた境界エッジ (要素・局所番号) と当たった点が分かる。二次電子・FN も同じ | K_ff の LU (厳密) |
| v2 GPU PIC (`gpic/simulation.py`・`kernels/pic.cu`) | デバイスの `eval_groups` が `vg` に書く | 境界のカーネル `boundary` で外周の辺 (st 1〜4) か固体 (導体の番号) が分かる | 小さければ密な逆行列、ほかは GMG-PCG を固定回数 (warm start)。1 ステップ全体が CUDA Graph でホストと同期しない |
| AMR の GPU PIC (同上、`-DES_AMR`) | 同上 | 同上 | 合成格子の AMG-PCG。動的再格子化で格子が変わる |

PIC では電極の電荷を Green の相反定理で求める (流体の「φ* を解いて ψ で直す」形は使わない):

- 全ての電極を 0 V にしたとき空間電荷が電極 k に誘導する電荷は Q_e0,k = −Σ_i ψ̃_k(i) q_i。q_i は節点の電荷
  (粒子の堆積・誘電体の表面電荷・固定の電荷。電極の固定節点に置かれた分も含む)、ψ̃_k は ψ_k の固定節点に
  「電極 k なら 1、ほかの電極なら 0」を入れたもの。離散の Poisson の行列が対称なら、流体で使った
  「電束 − 電極の固定節点の電荷」と厳密に同じ値になる (固定節点の電荷を引く形も、ψ̃_k = 1 の所に入っている)。
- よって V_e = (C + C_b)⁻¹ (Q_N − Q_e0 + C_b V_s) が Poisson を解く前に決まる。Poisson は新しい V_e で 1 回
  解くだけで、ψ の重ね合わせの直しは要らない。
- V_e は Poisson の解の精度によらない。GPU PIC の Poisson は反復の回数が固定で φ が厳密でないが、V_e は電荷
  だけから厳密に決まる (SB-b の計画の「電荷の誤差の扱い」はこれで決まる)。
- 伝導電流は電極ごとに粒子の電荷を数える: Q_N += Σ (吸収した粒子の q w) + Σ (電極から出た二次電子・FN の
  電子の e w)。粒子の電荷と Q_N の和は丸め誤差で保存する。
- 時刻: ステップ n の Poisson は t_n の粒子 (Q_N は t_n までに吸収した電荷を含む) で解く。リープフロッグの
  粒子の位置と同じ時刻なので、ずれは無い。

エンジンごと:

- PIC 1D: ψ̃ と C は流体 1D と同じ (直線、C = ε0/L)。q_i は CIC の堆積 (面積あたり)。
- v1 PIC: ψ は K_ff の LU (流体 v1 と同じ)、q は Poisson の右辺と同じ f = f_static + f_dep + q_surf (軸対称は
  2π を掛けて物理の電荷)。吸収した粒子の電荷は、越えた境界エッジの 2 つの端の節点へ当たった点の P1 重みで
  分け、端の節点が電極の Dirichlet 節点ならその電極へ (流体 v1 の壁エッジの端と同じ考え)。二次電子・FN の
  電子も、出た点で同じように分ける。
- v2 GPU PIC (一様格子・AMR): 1 ステップ全体が CUDA Graph なので、回路もデバイスで進める。
  - 誘導電荷: 電極ごとに 1 ブロックの決定的な和 Σ W_k(i) q_i (一様格子は W = −ψ̃。AMR は合成格子の電極の電荷の
    汎関数 (SB-d の a・b・c) を随伴の 1 回の求解で q の重みにしたもの)。
  - 新しい V_e: 1 スレッドで (C + C_b)⁻¹ (ホストで作る M×M) を掛け、グループの電位 vg を書き換える
    (eval_groups の後・右辺の前)。最初のステップで Q_N を置く。
  - 伝導電流: 境界のカーネルで電極ごとに atomicAdd (外周の辺 → その辺の電極、導体 → 導体の電極)。ステップの
    終わりに Q_N に足し、V_e と電流をデバイスの履歴に書く。
  - 周期の集計 (V_dc・|V1|・I_dc) は、ホストの BlockingCircuit が履歴を読むときにまとめて行う (同期を増やさない)。
  - AMR の再格子化: 格子が変わるたびに W と C・(C + C_b)⁻¹ を作り直す (Q_N はそのまま)。
- 電極と関係ない粒子の出入り (v1 の粒子注入、誘電体への吸収と誘電体の二次電子) は Q_N に数えない。

## 検証

1. 真空の分圧 (伝導電流 0): V_e = initial_bias_v + V_s·C_b/(C_b + C)。1D は C = ε0/L。2D は C が静電場 (/solve)
   の容量と一致すること。
2. 電荷の恒等式: 毎ステップ Q_N = Q_e(φ) + C_b (V_e − V_s)、かつ Q_N − Q_N(0) = ∫I_cond dt。
3. C_b → ∞ (初期バイアス 0) で直結の計算と一致する (相対 1e-9)。
4. 対称な放電 (1D、両側の γ が同じ、1 周波): |V_dc| が振幅の 1% 以下。
5. 電気的非対称効果 (EAE、1D、13.56 + 27.12 MHz、V0[cos(ωt+θ) + cos(2ωt)]): 理想値 η = −(φmax + φmin)/2 は
   θ = 0°: −0.44 V0、30°: −0.15 V0、45°: 0、60°: +0.15 V0、90°: +0.44 V0 (Heil ら, J. Phys. D 41, 165202 (2008))。
   符号と θ への依存の形 (ほぼ直線) が合い、大きさが理想値と同じ程度 (0.5〜1.5 倍) であること。理想値は
   2 つのシースの対称さ ε = 1 を仮定しており、ε がずれると大きくも小さくもなる。比べるときは、電極の実際の電位の
   交流分から理想値を求める (C_b による RF の分圧を除くため)。ES-Sim の RF は sin なので、位相は θ + 90° と
   90° を与える。
6. CPU と GPU の一致 (2D、V_dc の推移が相対 1e-8 程度)。
7. GEC (SB-b): C_b = 5 nF で V_dc が負になり、Hargis ら 1994 の 13 Pa と比べる (|V1| は電極の電圧の基本波の振幅)。

## SB-f の記録 (2026-10-03)

実装:

- `kernels/pic.cu`: 回路の 3 つのカーネル。`cap_induced` (誘導電荷 Σ W·(q_static + ρ + q_surf) を電極ごとに 64 ブロックの
  部分和、`cap_solve` が決まった順に足すので決定的)、`cap_solve` (1 スレッド: 最初の呼び出しで Q_N を置き、
  V_e = (C + C_b)⁻¹ (Q_N − Q_e0 + C_b V_s) をグループ電位 vg に書く。eval_groups の後・右辺の前)、`cap_step`
  (ステップの終わりに Q_N += dQ、V_e と電流をデバイスの履歴に書く)。境界のカーネルは吸収した粒子の q·w と電極から
  出た二次電子の +e·w を電極ごとに atomicAdd (外周の辺は `side_elec`、導体は `cond_elec`)。どれも CUDA Graph の中で、
  ホストとの同期は増えない。
- `gpic/simulation.py`: 誘導電荷の重み W と容量行列 (`_cap_weights`)。一様格子は ψ_j を GMG-PCG で解いて
  W_j = −2π ψ̃_j (周期の従属節点は 0)、容量は結合の電束 (v2 の流体と同じ)。AMR は電極の電荷の汎関数 a・b・c
  (流体 AMR と共通にした `amr.composite.electrode_charge_functionals`) から、随伴 y_j = A_c⁻¹ P_nodeᵀ a_j を
  ホストの疎行列 LU (大きければ AMG-CG) で 1 回解いて W_j = c_j + P_node y_j・C_jk = y_j·coup_c e_k + a_j·C_node e_k
  + b_j·e_k。動的再格子化のたびに作り直す (Q_N はデバイスにそのまま)。周期の集計はホストの BlockingCircuit が
  `_flush_history` で履歴を読むときに行う (`record`・`set_state`、再格子化は `set_capacitance`)。フレーム・結果
  (`batch.pic_circuit_result`)・続き。
- 共通: 直交格子の電極の引き方と集計の周期を流体 2D と共通にした (`circuit.model_capacitor_electrodes`・`rf_period`)。
  全てのエンジンが対応したので、未対応のエンジンのエラー (`reject_blocking_capacitors`・`blocking_capacitor_labels`)
  を消した。UI の説明・README・SPEC・スキーマの説明を「流体・PIC の全てで使える」に。
- テスト `tests/test_circuit_gpic.py` (11 件): 容量と真空の分圧 (一様格子・AMR × 平面・軸対称)、恒等式 (一様格子・
  AMR、小さい格子で Poisson が密な逆行列)、電荷の保存 (一様格子・AMR)、再格子化 (新しい合成格子の容量・Q_N・
  電荷の保存)、v1 PIC との自己バイアスの推移の一致、結果・フレーム・続き。電荷の保存の 2 件を NVRTC だけの環境の
  テストの一覧に足した。`test_circuit.py` は「全てのエンジンが回路を組む」に。

確かめたこと:

## GEC の PIC の検証 (prompts/135、2026-10-03)

GEC サンプル (検証の 7) の形・条件 (Ar 13.33 Pa・300 K、RF 電極 100 V・13.56 MHz、阻止コンデンサ 5 nF・初期バイアス
−85 V、γ = 0.07) に v2 GPU PIC の設定を足して走らせた: 断面積は eduPIC の Ar (Phelps の解析式、PIC 1D のプリセットと
同じ)、初め 1×10¹⁵ m⁻³・3 eV、1 周期 800 ステップ。

基準の計算 (直交格子 0.25 mm・14.7 万節点、400 万粒子、600 周期。RTX 5070 Ti で約 8 秒/周期):

| 周期 | 25 | 100 | 200 | 300 | 400 | 500 | 600 |
|---|---|---|---|---|---|---|---|
| V_dc (V) | −84.2 | −83.4 | −81.8 | −80.2 | −78.8 | −77.5 | −76.4 |

- 最後の 25 周期: V_dc −76.5 V、|V1| 99.0 V (比 0.77)、正味の伝導電流 0.77 mA。まだ 100 周期に約 1.1 V ずつ上がって
  いる (5 nF に 0.8 mA ほどの電流が流れ続けている。プラズマも 100 周期に数 % ずつ変わっている)。流体 (−85.2 V、
  比 0.86) より Hargis らの実測 (比 0.67〜0.72) に近い。
- 電子密度 (電極の間 z = 37〜48 mm の平均、r = 10〜40 mm) は 3.2〜3.5×10¹⁵ m⁻³ で、最後の 100 周期の増え方は 3.5%
  (r 15〜20 mm で 100 周期ごとに 21% → 12% → 8% → 5% → 3.5% と落ち着いていく)。中心の Te 2.9 eV、プラズマ電位
  22.6 V。流体 (最大 1.5×10¹⁵ m⁻³) の 2 倍余り。流体は電子の局所平均エネルギーの近似で、シースでの確率的な加熱の
  ような運動論の効果を含まないが、差の原因はここでは切り分けていない。

格子と粒子数 (100 周期の時間平均を、電極の間 z = 37〜48 mm で r の帯ごとに体積平均して比べた):

| | n_e、r 0〜1 mm (10¹⁵ m⁻³) | n_e、r 15〜20 mm | 電離 (r 0〜1 mm ÷ 15〜20 mm) | V_dc (V) |
|---|---|---|---|---|
| 0.25 mm・400 万粒子 | 2.46 | 2.04 | 2.2 倍 | −83.5 |
| 0.5 mm・400 万粒子 | 2.43 | 2.01 | 1.7 倍 | −83.3 |
| 0.5 mm・100 万粒子 | 4.24 | 2.31 | 6.7 倍 | −83.7 |

- 400 万粒子なら 0.5 mm と 0.25 mm は全ての帯で 4% 以内 (Te は 0.5 mm が 0.1 eV 高い)。h/λ_D ≈ 2 でも格子による
  加熱は目立たない。サンプルは流体と共通の 0.5 mm に 400 万粒子とした。
- 600 周期 (サンプルの保存された結果 (0.5 mm、最後の 50 周期の平均) と基準 (0.25 mm、最後の 25 周期の平均)):
  V_dc −76.2 V と −76.5 V (0.4%)、|V1| 99.0 V で同じ。電子密度は r 30〜50 mm で 3% 以内、r 15〜20 mm で 0.5 mm が 9%
  低く (2.95 と 3.25×10¹⁵ m⁻³)、Te は 0.5 mm が 0.15 eV (5%) 高い。軸の近くの密度の山 (r 0〜1 mm ÷ 15〜20 mm) は
  0.5 mm が 1.18 倍、0.25 mm が 1.30 倍で、細かい格子のほうが軸の近くの雑音の影響を強く受けている。
- → 2026-10-04 (prompts/136): マクロ粒子の重みを半径に比例させ (分割と対の併合)、軸の近くの山は無くなった
  (0.5 mm・100 万粒子で電離の比 0.98 倍)。サンプルの保存された結果 (200 万粒子・600 周期) の電子密度は軸から周辺へ
  増え、r ≈ 38 mm で最大 (Rauf 2020・Hara ら 2022 の PIC と同じ形)。自己バイアスは −76.6 V で変わらない。
- 100 万粒子では軸の近くの電離が 6.7 倍になり、軸の上の密度の山が育ち続けた (最大 7.9×10¹⁵ m⁻³、125 周期で
  止めた)。軸対称でマクロ粒子の重みが一定なので、軸の近くはセルあたりの粒子が r に比例して少なく、粒子 1 個の電荷が
  ほぼ点電荷として効く (統計の雑音による加熱は 重み/r に比例して強くなる)。400 万粒子でも軸の近く (r ≲ 5 mm) は電離が
  1.5〜2.4 倍、密度が r 15〜20 mm の 1.3 倍に出る (600 周期まで 1.3 倍のまま)。半径方向の重み付けなどの対策は別の
  作業として切り出した。
- 表示の注意: 軸の上の節点の時間平均の密度は、線形の重み付けと節点の体積 (双対セル) のため、一様なプラズマでも
  4/3 倍に出る (この計算では隣の節点の 1.2〜1.3 倍)。Poisson の右辺 (節点の電荷) は有限要素と同じ形で正しい。
