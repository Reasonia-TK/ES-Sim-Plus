# 123: v2 AMR P4c — PIC の動的再格子化 (デバイ長に基づく)

計画書: `prompts/119-v2-rebuild-plan.md` (P4)。前段: `prompts/121-amr.md` (静電場の合成格子)、
`prompts/122-amr-gpu-pic.md` (GPU 求解・AMR 上の PIC・適応細分化)。

## 目的

PIC の格子幅はデバイ長 λ_D 程度以下でないと数値加熱 (有限格子不安定性) が起きるが、λ_D は
密度・温度で場所ごとに変わり、放電が立ち上がるまで分からない。実行中の電子の密度・温度から
λ_D を求め、格子幅/λ_D が大きい所だけを細かくする (AMReX の regrid と同じ考え方)。

## 設定 (`mesh.amr`)

- `pic_regrid_every` [ステップ] (0 = 静的): この間隔で再格子化する
- `pic_h_over_debye` (既定 1.0): 格子幅/λ_D がこれを超えるセルを細かくする (上限は `max_level`)
- 境界近傍・指定矩形の静的な細分化 (`refine_boundaries`・`regions`) はそのまま併用される
- 動的再格子化が有効なら、始めに細分化が無くても AMR 経路で走る (L=0 は一様格子と機械精度で一致)

## 手順 (gpic/simulation.py `_regrid`、amr/pic_layout.py)

1. `TAG_EVERY` (8) ステップごとに電子の重み Σw·S と運動エネルギー Σ½mv²w·S を節点へ積算
   (CUDA Graph の外、同期なし)。
2. 再格子化のステップで κ = 1/λ_D = √(e n_e / (ε0 Te)) を節点ごとに求める
   (n_e = 積算/双対体積、Te = (2/3)⟨½mv²⟩/e)。
3. 候補の階層の各レベルの領域セルについて、角の点での κ (旧格子の双一次補間) の最大 × 格子幅が
   閾値を超えればタグ。候補で判定し直すことを階層が変わらなくなるまで繰り返す (新しい領域の中も
   一度で必要なレベルまで細かくなる)。既に細分化されている所は閾値 × 0.7 まで保つ (ヒステリシス:
   密度の揺らぎで細分化と粗視化を繰り返さない)。
4. 新しい階層が現在と同じなら何もしない。変わったら PIC の表・行列 (build_pic_layout) と
   GPU AMG-PCG を作り直し、状態を移す:
   - 粒子: 座標はそのまま (所属セルは毎ステップ es_locate で求めるので何もしない)
   - 誘電体の表面電荷: 旧節点の電荷を点電荷として新しい格子へ CIC で配り直す (総電荷を厳密に保存)
   - 前ステップ解 (warm start): 旧格子の電位を新しい節点で双一次補間
   - 時間平均・位相分解の節点配列: 再格子化は時間平均区間の前だけなので 0 のまま作り直す
   - CUDA Graph は取り直す
5. 表示用メッシュが変わったら、次のフレームに `mesh` (と `mesh_version`) を添える。server は古い
   フレームを捨てるときに mesh を新しいフレームへ引き継ぐ。done には最終の格子と再格子化の記録
   (`regrids`) を添える。フロントは mesh 付きのメッセージで表示格子を差し替える。

## 自己力について (P4b の測定を受けた判断)

粗細界面の自己力 (最大で「1 格子幅離れた同じ粒子の電場」の 0.28 倍) は、どの PIC でも導体壁の
近くでマクロ粒子が受ける自分の鏡像力 (壁から 1 セルで 0.5 倍) より小さく、物理的な像力と
切り分けて差し引く補正は難しい (壁際の像力まで消すと別の誤差になる)。そこで補正は入れず、
自己力による電位の目安 0.1·w·e/(2πε0) (軸対称は w·e/(2πr)) が電子・イオンの温度の 0.2 倍を
超えるときに警告を出す (粒子数を増やすよう促す)。

## 回帰で見つかった既存バグ (GPU PIC、同時に修正)

計算は非ブロッキングの CUDA ストリームに積んでいるのに、ホストが GPU の値を読む所
(history の読み出し・圧縮後の粒子数・PCG の残差監視・EEDF の自動範囲) でそのストリームの
完了を待っていなかった。フレームを作る実行 (UI のライブ実行) では history の末尾の行が 0 や
前周の値になっていた。読み出しの前に `stream.synchronize()` を入れた。
