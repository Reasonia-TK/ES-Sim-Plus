# 137: 時間発展の収束の判定 (計画)

依頼 (2026-10-05): 「収束判定機能を追加してほしい。例えば、サンプリング周期平均の電位や電子密度が前サンプリング
周期から変動率 0.1% 以下になったら収束フラグを立てるとか (ほかにもっと良い方法があれば教えて)」

決めたこと (2026-10-06):

- 判定は「改良した方式」: RF 周期の整数倍の周期平均で、φ・n_e (体積で重み付けした L2) と電子・イオンの総数・
  自己バイアス V_dc を見る。残りの変化の見積もり (外挿) と雑音の差し引きを使い、H 回続けて満たしたら収束。
  既定の閾値は流体 0.1%・PIC 1%。
- 収束したら、周期・時刻を結果に記録して表示する。設定の「収束したら止める」をオンにすると、そこから平均区間を
  取って止める (n_steps は上限になる)。
- 対象はプラズマの時間発展の全て: PIC 1D・2D (v1 の CPU・v2 の GPU、AMR も)、流体 1D・2D (v1・v2 の CPU/GPU・AMR)。

## 提案の方式 (前の周期との比較) の落とし穴

1. PIC は雑音で閾値に届かない: 周期平均の場にも粒子の統計の雑音が残り、前の周期との差は雑音の幅 (目安
   1/√(セルあたりの粒子数 × 周期の中の独立なサンプル数)) より下がらない。
2. 遅い変化を見逃す: GEC の PIC の自己バイアスは 600 周期でも 100 周期に約 1 V 動いている (prompts/134)。1 周期
   あたり約 0.013% なので「前の周期から 0.1% 以下」はとうに満たすが、まだ定常ではない。1 周期の変化 δ が小さくても、
   緩和の時定数 τ (周期) が長いと残りの変化 ≈ δ·τ は大きい。
3. そのほか: 周期が RF 周期の整数倍でないと RF の揺れが「変化」として残る。点ごとの最大の変化は雑音と密度の低い所に
   引きずられる。たまたま小さい周期で旗が立つ。

## 設計

### 標本 (周期平均)

- 判定の周期 T_s = `rf_periods` × RF の最低周波数の周期 (2D は `circuit.rf_period`、1D は `_cycle_freq` と同じ)。
  RF も CSV 波形も無い計算は `steps` ステップ (未指定なら 10 × frame_every)。境は絶対時刻 floor(t / T_s) で決める
  (阻止コンデンサの周期の集計と同じ境。続きの実行でもずれない)。
- 周期 k ごとにエンジンが周期平均 x_k を渡す:
  - 場: φ と n_e (気体の節点)。粗いブロック (2D は約 32×32、1D は 64 個の軸平行の矩形) に節点の体積 (軸対称は
    2πr を含む) で平均してから比べる。PIC の粒子の雑音が大きく減り (GEC の 0.5 mm 格子ならブロックに約 30 セル)、
    AMR の再格子化で節点が変わってもブロックは同じなので比べ続けられ、標本の記憶も小さい。PIC は数ステップおきに
    足す (1 周期に 64 回ほど)。流体・PIC 1D は毎ステップ。
  - 積分量: 電子・イオンの総数 (Σ n·V、PIC は Σw)。
  - 阻止コンデンサの電極ごとの V_dc (その周期に閉じた RF 周期の V_dc の平均)。尺度は |V1| (基本波の振幅)。

### 判定 (量ごと、周期の終わりごと、`es_sim/convergence.py`)

- 雑音: 三階差分から周期ごとの雑音の分散を見積もる σ² ≈ mean‖x_j − 3x_{j−1} + 3x_{j−2} − x_{j−3}‖² / 20 (白色雑音
  なら不偏、2 次までの変化は消える)。二階差分は、雑音の無いゆっくりした減衰の曲がり (1/τ 倍) を雑音として拾い、
  下の q の誤差と区別できなかった (三階差分なら (1/τ)² 倍)。流体では ≈ 0。
- 窓 W: 窓の平均どうしの比較の雑音の幅 √(2σ²/W)/‖x̄‖ が閾値の半分以下になる最小の W (1〜`max_window`)。
  最大でも足りなければ「雑音が大きく判定できない」(閾値を上げるか周期を長くする)。量ごとの W の最大を全体の W に。
- 変化 D: B = 直近 W 周期の平均、A = その前の W 周期の平均。D = √max(0, ‖B − A‖² − 2σ²/W) / ‖B‖ (雑音を差し引いた
  相対変化。V_dc は ‖B‖ の代わりに |V1|)。
- 残りの変化 R: 窓 W' の平均を 3 つ (B'・A'・A'') 並べて Δ1 = B' − A'、Δ2 = A' − A''、q = ⟨Δ1, Δ2⟩ / ‖Δ2‖² (窓ごとに
  変化が減る割合)。R = D'·q⁺/(1 − q⁺) (等比で減るとみなした残り、Aitken の外挿。D' は窓 W' の変化)。
  - q⁺ = |q| + 2·SE(q)、SE(q) ≈ √(2σ²/W' / ‖Δ2‖²)·√(1 + q²)。q⁺ ≥ 1 なら無限大 (雑音のある遅い傾きは、減っていると
    言い切れるまで合格しない。誤差を見ないと、雑音でまっすぐな傾きを「減っている」と見誤ることがあった)。
  - W' は W から広げ、Δ1 が雑音の幅の 3 倍を越える (有意な) 最初の窓 (雑音に埋もれた遅い傾きも長い窓で見つける。
    何度も試すので 3σ)。標本の範囲 (最大 3·max_window + 2 周期) で有意な変化が無い、または丸め誤差 (1e-10) 以下
    なら 0。
  - 外挿はこれまでの周期の数の 10 倍 (HORIZON) の先までにとどめる: R = min(等比の外挿, D'/W' × 10 × 周期の数)。
    観測した長さよりはるか先の外挿は当てにならず、閉じた系の 1 周期 6×10⁻⁸ の数値的なずれ (減らない傾き、または
    時定数 1 億周期で減るように見える) で無限大や無意味な値 (残り 700%) になって、いつまでも合格しなかった。時定数が
    これまでの長さの 10 倍までの緩和は見逃さない (10 倍を越える緩和は見分けられない限界)。雑音の中の 1 周期 0.1% の
    傾き (300 周期で 300%) や GEC の自己バイアスの遅い動き (600 周期で 1 V/100 周期) は今どおり不合格。
  - 流体の W = 1 では「前の周期との変化 × 時定数」になる。
- 合格: 全ての量で W が足り、D ≤ tol かつ R ≤ tol。`hold` 回 (既定 3) 続けて合格したら収束 (その周期・時刻・
  ステップを記録)。判定には 3W 周期と雑音の見積もりの分 (7 周期) が要る (それまでは「判定中」)。雑音のある量
  (周期ごとの雑音が閾値の 1% を越える) があるときは 3 × max_window 周期まで判定しない (標本が少ないと雑音に
  埋もれた傾きを探す範囲が足りず、早すぎる合格になった)。
- 収束の記録は最初の 1 回。そのあと合格しなくなったら「今は満たしていない」と出す。

### 止める (`stop`)

- 収束を見つけたステップ s から平均区間 avg (avg_steps、未指定なら判定の周期 10 個分) を取って止める:
  終わり = min(今の終わり, s + avg)。終わりが早まるときは時間平均・位相分解・コレクタ・EEDF の区間の始まりを
  s + 1 に移す (まだ始まっていないので移すだけ)。最後の 1 周期の粒子の写しの始まりも直す。
- 止めた実行は「完了 (収束で停止)」。続きの実行では、前に収束していれば止めない (n_steps まで走る)。

### 続き・再格子化

- 判定の状態 (標本・履歴) は続きの実行に引き継ぐ (周期の境は絶対時刻なのでそのままつながる)。
- PIC の動的再格子化で節点が変わったら、ブロックへの対応だけ作り直す (ブロックは同じなので標本は続けて比べる)。

### 設定 (`convergence`、PIC 2D・PIC 1D・流体 1D・流体 2D の設定の中)

| 項目 | 既定 | 意味 |
|---|---|---|
| `enabled` | true | 判定する (軽い) |
| `tol` | 自動 | 閾値 (相対)。自動は流体 0.001・PIC 0.01 |
| `rf_periods` | 1 | 判定の周期 (RF の最低周波数の周期の何個分) |
| `steps` | 自動 | RF が無いときの判定の周期 [ステップ]。自動は 10 × frame_every |
| `hold` | 3 | 何回続けて満たしたら収束とするか |
| `stop` | false | 収束したら平均区間を取って止める |
| `max_window` | 20 | 窓の最大 [周期] (詳細) |

### 結果・表示

- 結果の `convergence`: 閾値・周期・周期ごとの時刻と量ごとの D・R・雑音の幅・窓、収束した周期・時刻・ステップ、
  収束で止めたか。フレームには今の状態。無限大・未計算は null (状態 "fail" で R が null なら無限大)。結果の束
  (保存) は既定の 7 桁 (時刻の列があるので桁を落とさない)。
- UI (CV-c): 各スタディの設定に「収束の判定」、実行のページの数値サマリに状態、グラフに量ごとの max(D, R) の推移
  (対数、閾値の線、収束の印)、スイープのケースの一覧に収束の列。

## 確かめること

1. 判定の部品 (人工の数列): 指数で近づく (τ = 300 周期、1 周期の変化 0.03%) を前の周期との比較のようには早く
   合格させず、残りが閾値を下回ってから合格。白色雑音だけ (PIC 相当) は窓が広がって合格。雑音 + 遅い傾きは傾きが
   小さくなるまで合格しない。振動、0 の場、V_dc の尺度、hold、場の標本の捨て直し。
2. 流体 1D・2D: 周期が RF 周期にそろう。収束が記録される。止める設定で、収束から平均区間を取って止まり、時間平均が
   その区間になる。続きの実行で状態がつながる。CPU/GPU で同じ判定 (GPU は丸め誤差の範囲)。
3. PIC 1D・2D (v1・v2): 同じ。GPU PIC の 1 ステップの時間の増え方 (目安 +2% 以内)。
4. GEC (流体・PIC): いつ収束と判定されるか、V_dc の遅い変化で早く合格しないか。

  φ・n_e (気体の節点) と電子・イオンの総数 (履歴の値) を足し込み、周期の境で判定する。GPU 版 (`gfluid/gpu.py`) は
  場をデバイスのまま足し込み、周期を閉じるときは計算のストリームの上で写す (別のストリームから読むと計算の途中の
  値を読むおそれがある)。`run_batch` の終わりを変えられる形にし、収束で止めるときは時間平均・位相分解の区間を
  収束の次のステップから取り直す。結果 (`build_*_result`) とフレームに `convergence`。
- 作りながら直したこと (計画の設計の節に反映):
  - 二階差分の雑音の見積もりでは、雑音の無い遅い減衰 (τ = 300 周期) の R がいつも無限大になった → 三階差分。
  - 「D が閾値の 1/100 以下なら R を見積もらない」は τ > 100 周期の遅い緩和を早く合格させた → 丸め誤差 (1e-10) に。
  - 雑音の中の傾き (1 周期 0.1%、雑音 0.5%) を、3 つの窓の比 q のぶれで「減っている」と見誤った → q の誤差の上限
    q⁺ と、雑音のある量は 3 × max_window 周期まで判定しない (標本が少ないと 10〜17 周期で早すぎる合格になった)。
  - 閉じた系の 1 周期 6×10⁻⁸ の数値的なずれで R が無限大 (AMR では時定数 1 億周期の等比の外挿で残り 700%) になり、
    いつまでも合格しなかった → 外挿の上限。初めは「これまでの周期の数 × 今の速さ」にしたが、流体 1D の CCP で R が
    44% → 33% に下がったのを見て、時定数がこれまでの長さより長い緩和を早く合格させうると分かり、10 倍の先までに
    した (テスト: 時定数 2 万周期・残り 50% の減衰を初めの 40 周期で合格させない。1 倍だと 7 周期で合格した)。
- 実例 (流体 1D の CCP、test_fluid1d の CCP と同じ 50 Pa・ギャップ 25 mm・150 V、dt = RF/400): 前の周期との比較
  (周期の終わりの電子の総数で 0.1%) は 306 周期で合格するが、判定は 300 周期で残りの変化を 45% と見積もって合格
  させない。実際に 300 → 600 周期で電子の総数はさらに 22% 増え (6.6 → 8.1×10¹³)、600 周期でも残りの見積もりは
  21% (時定数 約 420 周期)。続けて走らせると (1 周期 約 1.2 s、2 時間の上限で 3000 周期あまりで止まった)、最も
  大きい max(D, R) は 300・600・1200・2100・3000 周期で 33%・21%・6.2%・1.2%・0.24%、電子の総数は 6.6・8.1・
  9.3・9.8・9.9×10¹³ (300 周期の値の 1.5 倍)。300 周期での残りの見積もり (45%) は実際の増え方と同じ程度。
  0.1% に届くのは 3500 周期前後の見込み (減り方からの推定、走らせては確かめていない)。
