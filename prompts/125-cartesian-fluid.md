# 125: v2 P5b — 流体 2D の直交格子 + 埋め込み境界 (EB) 版

計画書: `prompts/119-v2-rebuild-plan.md` (P5)。v1: `es_sim/fluid2d.py` (prompts/111〜117)。

## 目的

mesh.mode="cartesian" の流体 2D は、これまで同じ解像度の構造格子 (三角形分割・階段近似) に
フォールバックしていた。v1 の構造格子は格子幅の丸め方が v2 と違う (round(W/h) と m·2^k) ため、
フロントの `/mesh` (v2 の表示用メッシュ) と節点が食い違うという問題もあった。v2 の格子・EB・
Poisson をそのまま使う版を作る。

## 実装 (es_sim/gfluid)

- `CartesianFluid2dSimulation(Fluid2dSimulation)`: v1 の物理・時間積分・外部インターフェースは
  そのまま継承し、`_init_geometry` (輸送グラフ・壁)・`_init_poisson`/`_solve_phi` (Poisson)・
  `_wall_en` (壁向きの電場) だけを差し替える。v1 側はこの 3 つをメソッドに切り出しただけ
  (構造格子・非構造の両方でビット一致を確認)。
- 輸送グラフ (`gfluid/geometry.py`): 節点中心の有限体積。制御体積は双対セルの気体部分
  (EB Poisson の vol_gas と同じ積分)。エッジ重みは 2 つの半チューブの開口面積 / 辺長で、境界が
  通る半チューブは辺に平行な 8 本の標本線のうち端から端まで気体中を通るものだけを数える
  (薄い固体越しに漏れない。全て非負なので常に M 行列)。直角三角形分割の EAFE は斜辺の重みが 0
  なので、固体の無い領域では v1 構造格子と同じ 5 点ステンシル (節点体積だけ違う: v1 の P1 集中
  質量は市松に 4/3·h² と 2/3·h² が並ぶ)。
- アクティブ節点 = 固体の厳密な内部に無い節点 (表面上の節点は壁節点として残す)。固体内部の
  節点にかかる気体の小片・壁は、隣接するアクティブ節点へ気体体積比で併合する (総体積を保存。
  Poisson の電荷は小片の元の双対セルに置く)。
- 壁: 外周 (symmetry・rz 対称軸以外) と固体表面。表面は格子幅の 1/4 以下の小片に分け、面積
  (軸対称は 2π r 倍)・法線・SEE γ を気体側の点を含む双対セルの節点に持たせる (1 小片 = v1 の
  壁エッジの片側)。壁向き電場 E·n = (φ(A) − φ(W))/L (W: 壁上の点、A: 1 格子間隔気体側、
  導体の φ(W) は電極電位)。外周では A がちょうど隣の節点になる。
- Poisson: EB の離散化 (eb.build) をそのまま使う。節点数 6 万以下は疎行列 LU を 1 回だけ分解
  (小さな格子で GPU の反復法より速い: 42 節点の 1D 比較で GPU GMG 8.0 s → LU 1.3 s)、それより
  大きいか Dirichlet の無い特異な問題は GMG-PCG (GPU があれば GPU、前ステップの解から)。
- mesh.amr は未対応 (警告して基準格子で解く。→ prompts/128 で対応)。/ws/fluid2d の started とバッチの ResultsBundle に
  表示用メッシュを載せ、フロントはそれを描画用メッシュにする (AMR 設定時に `/mesh` と食い違わない)。
- server・batch は `make_fluid2d_simulation` で mesh.mode により振り分ける。

## 既知の制限 (v1 と共通)

- 誘電体表面と「なし (Neumann)」の外周辺は吸収壁だが帯電しない (Poisson に表面電荷が無い) ため、
  電子だけが抜けて空間電荷が正に偏り、電位が際限なく上がることがある (UI の既定サンプルで再現)。
  → prompts/129 で解消 (誘電体の表面は帯電して浮遊電位へ、Neumann の外周辺は反射壁)。
- その状態では 1 ステップのサブステップ数が際限なく増え、停止がステップ間でしか効かないため
  応答しなくなる。
