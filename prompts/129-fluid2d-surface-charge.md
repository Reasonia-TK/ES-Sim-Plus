# 129: 流体 2D — 誘電体表面の帯電と、境界条件なし (Neumann) の外周辺の反射壁化

対象: v1 `es_sim/fluid2d.py` (三角形メッシュ) と v2 `es_sim/gfluid` (直交格子 + EB、prompts/125)。
2D PIC (pic.py・gpic) は誘電体の表面電荷 q_surf を既に持っている (prompts/25)。

## 問題

誘電体の表面と「なし (Neumann)」の外周辺は、粒子を吸収するのに帯電しなかった (Poisson に表面電荷が
無い)。電子の熱流束 (~n·v̄_e/4) はイオン流束より桁違いに大きいので電子だけが抜け、空間電荷が正に
偏って電位が kV まで暴走し、サブステップ数が際限なく増えた (UI の既定サンプル: 100×50 mm・誘電体
ブロック・右辺 100 V の DC/RF・流体 2D の既定値。上下を symmetry にしても誘電体があれば再現)。

Neumann の辺は帯電させても解決しない向きの問題もある: 正の空間電荷と ∂φ/∂n = 0 の組み合わせでは
その辺がその方向の電位の山になり、電子を押し返す電場ができない。

## 決定 (ユーザー確認、2026-09-29)

- 誘電体の表面: 吸収 + 表面電荷の蓄積 (浮遊電位へ緩和する)。電極 (Dirichlet・導体) は従来どおり
  吸収して外部回路へ流す (帯電しない)。
- 境界条件なし (Neumann) の外周辺: **反射壁** (粒子・エネルギー流束 0。流体では symmetry と同一)。
  浮遊帯電壁にする案もあったが反射を選んだ。外周で粒子を失わせたい辺は電極として指定する。
  PIC の「なし」辺 (吸収・帯電なし) は変更しない。

## 実装

- 表面電荷 `q_surf` [C] は節点ごとの状態変数 (xy は奥行き 1 m あたり、rz は 2π 込みのリング電荷 —
  pic.py と同じ規約)。続き実行 (prepare_continue) でも保持する。history に合計 `surf_q` を追加。
- 帯電する壁端の表 (`_set_surface_charge_ends`: surf_elem/surf_loc/surf_node/surf_area): 壁要素の片側
  ごとに、流束を評価する輸送節点と面積。毎サブステップ、電子を解いた直後に
  `q_surf += e·dt·Σ area·(c_i·n_i·(1+γ) − (v̄_e/4)·n_e)` (壁損失 gw_i・gw_e と同じ係数・同じ新しい密度。
  節点で足すと gw_i − gw_e に一致するので、プラズマから出た電荷は過不足なく表面へ移る)。
- Poisson: v1 は電荷ベクトル (FEM の「2π を後から掛ける」規約) に、v2 は EB の右辺 b (2π なし) に
  q_surf を足す (rz は 2π で割る)。陽的 (前サブステップまでの q_surf で解く) で、既存のサブステップ上限
  (誘電緩和時間・拡散 CFL・Joule) の範囲で安定に浮遊電位へ緩和した (下の検証)。
- v1: 自然境界の外周辺 = symmetry の辺 + どの境界条件にも指定されていない辺 (`_build_boundary_tables`
  で分類)。帯電する壁端 = 誘電体の壁エッジの両端のうち Dirichlet でない節点 (Dirichlet の節点 =
  電極との接点に落ちる分は電極へ流れる)。
- v2: `_side_walls` は Dirichlet の辺だけを壁にする。`FluidGraph.wall_dielectric` (誘電体表面の小片)。
  電荷は小片を受け持つ輸送節点 (wall_node) に置き、その節点が Poisson の固定節点なら電極へ流れる扱い
  (`_adopt_graph` で設定、未知節点の判定は `_poisson_unknown`)。
- v2 AMR (gfluid.amr_graph / amr): `_side_walls_amr` も Dirichlet の辺だけ、`AmrFluidGraph` にも
  wall_dielectric。未知節点の判定は合成格子の `fixed_group < 0` (ぶら下がり節点を含む: その電荷は PTq が
  親の未知数へ配る)。Poisson は q_all に q_surf (rz は /2π) を足してから PTq。
- GPU (gfluid.gpu・kernels/fluid.cu): q_surf はデバイスが正 (`_DeviceField`、全節点)。電子を解いた直後に
  `fl_surf` が節点ごとに壁小片の CSR (wptr) を走って帯電する小片だけを足す (原子演算なし、決定的)。
  `fl_poisson_rhs` に q_surf/qdiv を足す (EB・AMR の両方の経路)。history の surf_q は `fl_sum` (固定木の
  部分和) で集約し、stat の配置は変えない。
- サブステップの合間の停止要求 (4babddc) で状態をステップ開始時へ戻すとき q_surf も戻す (v1 の
  `_save_step_state`、GPU はデバイスの配列をその場で)。
- 派生クラスが表を設定しなければ帯電しない (基底クラスの既定は空)。

### v2 の電荷の置き場所

| 置き方 | 静的な精度 (与えた σ の電位) | UI 既定サンプル DC (1000 ステップ) |
|---|---|---|
| 界面を挟む 2 節点へ ε の直列比で分ける | 格子に揃わない界面でも 1D 厳密 | 誘電体の内部 −59 V (周りのプラズマ 104 V、輸送節点 85〜97 V) |
| 界面の点を含む双対セルの節点 | O(h) (ε_r=4・界面が格子幅の 1/4 ずれで 13%) | その節点が固体内部 (併合元) の小片で同上の問題 |
| **小片を受け持つ輸送節点 (採用、v1 と同じ)** | O(h) (同上) | 内部 99〜105 V、輸送節点 94〜99 V |

壁の流束条件は壁の密度をその節点の密度で代用する (Γ_e = n_e·v̄_e/4) ので、浮遊には輸送節点の電位が
下がる必要があり、電荷も同じ節点に置くのが整合する。シースが格子で解像されない粗い格子 (既定サンプル
h = 3.8 mm ≫ λ_D = 0.33 mm) では、電荷の約 7 割を固体側の節点に置くと誘電体の内部が大きく負になった
(表面電荷の総量は流束の釣り合いで決まるので −62 / −64 nC/m とほぼ同じ)。与えた σ に対する静的な電位は
O(h) の誤差になるが、浮遊電位そのものは流束の釣り合いで決まるので影響は小さい。

## 既知の制限・別件

- 既定サンプルの DC で陰極シースの電子がほぼ空の節点 (n_e ~1e6〜1e8) の Joule 加熱の安定条件が極端に
  縮む問題 (誘電体の有無によらない) は、τ_J の最小値からその節点を除く修正 (0fa8c6c) で解消した。
  既定サンプルのテストは v1・v2 とも 1500 ステップ (平均 1.0〜1.9 サブステップ/ステップ)。
- 表面電荷は誘電体の表面ごとの一様な量ではなく節点 (壁端) ごとに浮遊する (誘電体は等電位ではない。
  物理的に正しい振る舞い)。
- PIC の Neumann 辺は吸収のまま (流体とは振る舞いが違う)。
