# 104: 1D プラズマ流体モデル — 実装計画 (プランのみ、個別実装は 105〜)

## 目的

ドリフト拡散近似の 1D プラズマ流体モデル (n_e・n_i の連続の式 + 電子エネルギー
方程式 + Poisson 自己無撞着) を新スタディ「流体 (1D)」として追加する。
既存の 1D PIC/MCC と**同一条件・同一プリセット・同一表示**で直接比較できる
ことを最重要の設計目標にする (流体は PIC より桁違いに速く、高圧・長時間・
パラメトリック検討に向く。低圧では PIC との乖離が物理的に意味を持つ)。

## モデル

- 連続の式: ∂n±/∂t + ∂Γ±/∂x = S、Γ± = ±μ± n± E − D± ∂n±/∂x
- 電子エネルギー: ∂w/∂t + ∂q/∂x = −e Γ_e E − Σ (損失)、w = (3/2) n_e T_e、
  q = (5/3)(−μ_e w E … SG 型)
- Poisson: −ε0 φ'' = e(n_i − n_e)、両端 Dirichlet (v_dc + RF + CSV 合成は既存流用)
- 数値法: **Scharfetter–Gummel フラックス** + 半陰的時間積分 (電子連続と Poisson
  の結合を陰化して誘電緩和時間制約を回避)。三重対角 solve_banded ×3/step。
- ソース/係数: 既存の断面積 (lxcat インポート / eduPIC Ar 解析式) から
  Maxwell 平均レート係数 k(T_e)・運動量移行 ν_m(T_e) → μ_e・D_e (Einstein)。
  イオンは低電界移動度 μ_i を入力 (既定 Ar+ 実測値)、D_i = μ_i T_i。
- 境界: 電極で熱流束+吸収、SEE γ (イオン流束比例)、電子は半 Maxwell 流束。

## 検証項目 (Phase B/E のテスト)

1. **両極性拡散減衰**: ソース無し・接地両端で基本モードの減衰率が
   D_a·(π/L)² に一致 (D_a = (μ_i D_e + μ_e D_i)/(μ_e + μ_i))
2. **ボルツマン平衡**: 定常・無衝突源で n_e ∝ exp(eφ/T_e)
3. **SG フラックスの極限**: ペクレ数 →0 で中心差分、→∞ で完全風上に一致
4. **保存性**: 粒子収支 (生成 − 壁損失 = ∂N/∂t) が機械精度
5. **eduPIC Ar 基準ケースで 1D PIC と比較**: 中心密度・T_e・シース厚が
   ファクター 2 以内 (流体/PIC の乖離は低圧では物理的に既知のため緩め。
   乖離自体を結果ビューで見られるのが本機能の価値)
6. continue ビット一致、結果付き保存/読込、既存テスト全パス

## 流用資産

- 断面積 (XsProcess・lxcat・eduPIC Ar 解析式)、電圧波形合成 (_eval_rf/_eval_waveform)
- Brinkmann シースエッジ (プロファイルに対してそのまま適用可)
- Plot1dView のチャート部品・位相分解 (cycle) の枠組み・sweep/batch の module 機構
- プリセット (eduPIC Ar / Turner He) — 流体側でも同条件ボタンを共有

## リスクと対策

- **半陰結合の安定性** (最大リスク): Phase B は「まず陽的 Poisson + 小 dt で
  正しさ確認 → 半陰化で加速」の2段構えにし、両者の一致テストを入れる
- 流体 BC の選択で結果が動く: BC は文献標準 (Hagelaar & Kroesen 系) を採用し
  docstring に出典明記
- T_e 低温側の係数テーブル外挿: テーブル範囲外はクランプ + warning
