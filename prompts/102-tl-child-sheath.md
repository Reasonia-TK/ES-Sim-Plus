# 102: TL モデルに Child 則型シース (定常高調波の生成源) を追加

## 背景

prompts/101 の実装過程で判明した問題: 対称放電で行列シース V_s(q) = q²/(2eε0n_s)
を上下直列にすると、dq_a/dt=+J・dq_b/dt=−J により q_a+q_b が保存され、

    V_a − V_b = (q_a² − q_b²)/(2eε0n_s) = 2q0·Δq/(2eε0n_s)

と**厳密に線形化**する。高調波はシース崩壊 (q=0 クリップ) の過渡でしか生成されず、
クリップは DC 電荷を押し上げるラチェットとして働き数周期で自己消滅する
(prompts/101 のテスト2が過渡窓を使わざるを得なかった理由)。
「定在波+波長短縮による高調波」の検証には**定常的に高調波を生む非線形性**が必要。

## 対策: sheath_law = "child" の追加

Child-Langmuir 型のシース (イオン密度がシース内で減衰する現実的なプロファイル)
では電荷-電圧関係が非2次になり、上下差し引きでも非線形性が残る:

    V_s(q) = K·q^{4/3}
    (q0+Δ)^{4/3} − (q0−Δ)^{4/3} は Δ の奇数次項 (Δ³, Δ⁵, ...) を含む
    → 対称放電でも奇数次高調波 (3f0, 5f0, ...) が定常生成される。
    偶数次は対称性で相殺 (実放電の偶数次は非対称性由来 — 将来拡張のコメントを残す)

### 規約

- schema: `TlSettings.sheath_law: Literal["child", "matrix"] = "child"`
  (新機能なので既定を child にする。matrix は線形極限検証・比較用として残す)。
- **小信号容量の整合**: 平衡点 q0 での微分容量が matrix と一致するように K を決める:
  dV_s/dq |_{q0} = s0/ε0  →  K = (3/4)·(s0/ε0)·q0^{-1/3}
  (これにより線形極限の実効波長 λ_eff は sheath_law に依らず同一 — 波長短縮の
  理論検証テストが両則で共通に成り立つ。理由コメント必須)。
  q0 = e·n_s·s0 (従来どおり)。
- q < 0 のクリップ (シース崩壊の整流) は child でも同様に適用 (強駆動時の追加
  非線形として物理的に正しい)。
- linear=True (テスト専用) は従来どおり線形容量で、sheath_law に依らない。

## テスト (tests/test_tl.py に追加/更新)

1. **定常高調波**: sheath_law="child"、定常窓 (n_periods=120、n_fft_periods=32、
   最後の窓) で中心近傍の |V_3|/|V_1| ≥ 1e-3 かつ |V_3| が |V_5| より大きい
   (奇数次の階段)。同条件の "matrix" では |V_3|/|V_1| が child の 1/10 未満
   (クリップ過渡が消えた定常では実質線形に戻るため)。
2. **偶数次の相殺**: child 定常で |V_2|/|V_1| < |V_3|/|V_1| (対称なら偶数次は
   奇数次より十分小さい)。
3. **線形極限の波長不変**: 既存の λ_eff ≈ λ0√(2s0/l) テストが sheath_law="child"
   でも (小振幅 V0 で) 同じ許容誤差で通ること — 小信号容量整合の検証。
4. 既存9テストは全パスのまま (matrix の既存挙動不変。既定値変更で参照している
   テストがあれば明示的に sheath_law を指定して意図を保つ)。

`python -m pytest tests/ -q` 全件パス。
