# 127: v2 P5d — GPU DSMC の AMR 対応 (葉セル = 衝突セル、平均自由行程での動的再格子化)

計画書: `prompts/119-v2-rebuild-plan.md` (P5)。前段: `prompts/124-gpu-dsmc.md` (GPU DSMC)、
`prompts/121-amr.md`・`122-amr-gpu-pic.md` (AMR 階層・ブロック表による所属セル判定)。

## 目的

GPU DSMC は一様な直交格子のセルで衝突・サンプリングしていた。DSMC のセルは平均自由行程 λ より
小さくなければならない一方、λ は圧力 (密度) で桁が変わる (入口側の高圧部だけ細かいセルが要る)。
`mesh.amr` の階層の葉セルを DSMC のセルにし、実行中に区間平均の密度・温度から求めた λ に合わせて
格子を作り直せるようにする。

## 実装

- `amr/cell_layout.py` (新規): `AmrCellLayout` = 葉セルの並び (セル番号 = ブロック番号·bf² + ブロック内の
  番号、最細レベルの格子上のブロック表 dd/di、細分化済みマスク、セルごとの気体体積・レベル・中心、
  4 近傍の隣接表、表示用メッシュ)。`cell_of_points` (ホスト側の所属セル)、`smooth_cells` (面を共有する
  葉セルの組の対称拡散。重み = 小さい方の気体体積 × 共有面の長さ / 短い方の面の長さ で、レベルを
  またぐ面も同じ式。総量保存・正値)、`mfp_tags`、
  `build_cell_layout`。`amr/pic_layout.py` のブロック表 (`block_index`・`cell_id`) を共用。
- `kernels/dsmc.cu` の `-DES_AMR` 変種: 移動の終点の葉セルを `ds_leaf_cell` (ブロック表を粗い方から
  辿る、O(レベル数)) で求める。`dsmc_relocate` は再格子化の後に全分子のセル番号を付け直す。
  固体との交差・反射・外周の処理は一様版と同じ (セルに依存しない)。
- `gdsmc/simulation.py`: 細分化が起きる (または動的再格子化が有効) なら葉セルを計算セルにする。
  時間刻みの既定は到達しうる最細レベルの格子幅で決める (再格子化で時間刻みを変えない)。
  結果は葉セルを 2 三角形に分けた表示用メッシュ (/mesh の AMR 表示と同じ) の要素ごとの値。
- 動的再格子化 (`mesh.amr.dsmc_regrid_every` > 0、`dsmc_h_over_mfp` 既定 0.5): 平均区間の前だけ、
  4 ステップごとにセルの分子数・速度・速度² を積算し、間隔ごとに λ = 1/(√2 n σ_VHS(T)) を求める。
  格子幅/λ が閾値を超えるセルをタグし (候補セルの中心と 4 隅を含む旧格子の葉セルの λ の最小で判定)、
  階層が収束するまで作り直す。既に細かいセルは閾値 × 0.7 まで保つ (ヒステリシス)。分子は座標・速度の
  まま、(σc_r)_max は新しいセルの中心を含む旧セルの値を引き継ぐ。境界近傍・指定矩形の静的な細分化は
  常に保つ。`regrid_log` に各回の葉セル数を残す。
- スキーマ: `AmrSettings.dsmc_regrid_every` (0 = 無効)・`dsmc_h_over_mfp`。UI はメッシュ欄の AMR 設定に
  「DSMC の動的再格子化 (平均自由行程)」を追加。

## 検証 (tests/test_v2_gdsmc_amr.py、CUDA が無ければ skip)

| 項目 | 結果 |
|---|---|
| 密閉箱 + 指定矩形 (L1) + 円形導体の境界 (L2) | どのレベルでも密度・温度が 2% 以内で一様、導体内に分子が入らない、時間刻みは最細レベルで決まる |
| 圧力駆動チャネル (20 → 5 Pa)、左半分だけ L1 | 一様な細かい格子と 4 区間の圧力が 3% 以内で一致、流入 = 流出 (10%) |
| 平均自由行程での再格子化 | λ の短い所だけ L2 まで細分化 → λ が伸びると粗視化。ヒステリシス (比 0.42 は新規の閾値 0.5 未満だが保持の閾値 0.35 超で L2 を保つ)。分子の数・位置・セル番号・セルごとの個数が保たれる |
| 実行中の再格子化 (40 → 1 Pa のチャネル) | 平均区間の前だけ再格子化し、入口側 (高圧) ほど細かい |
| 軸対称の密閉円筒 (軸上を L1) | 径方向・レベルによらず密度・温度が 3% 以内で一様 |
| /dsmc | 結果の表示用メッシュが /mesh の AMR 表示と同じ |
