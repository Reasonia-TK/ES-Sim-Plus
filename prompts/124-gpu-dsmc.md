# 124: v2 P5a — GPU DSMC (直交格子 + 埋め込み固体)

計画書: `prompts/119-v2-rebuild-plan.md` (P5)。v1: `es_sim/dsmc.py` (prompts/54〜89)。

## 目的

v1 の DSMC は三角形メッシュの隣接 walk で分子の所属セルを追っており、実機で実行時間の 97% を
walk が占めていた (prompts/88)。直交格子なら所属セルは O(1) で、GPU の粒子基盤 (v2 PIC) を
流用できる。v1 と同じ物理・同じ外部インターフェースで GPU 版を作る (mesh.mode="cartesian")。

## 実装 (es_sim/gdsmc、kernels/dsmc.cu)

- `GpuDsmcSimulation`: v1 `DsmcSimulation` と同じ run / prepare_continue / mesh / dt / x /
  step_count / timing / DsmcResult。server の /dsmc・/ws/dsmc は `make_dsmc_simulation` で
  mesh.mode により振り分ける。結果は表示用メッシュ (セルの 2 分割) の要素ごとの値なので、
  v1 PIC の背景ガス場 (use_dsmc_gas、要素重心マッピング prompts/89) にもそのまま渡せる。
- 1 ステップ: 流入 (dsmc_inject、区間ごとに流量 × dt / W の端数持ち越し) → 移動と境界
  (dsmc_move) → セル番号で基数ソート (CuPy argsort、吸収分子は末尾) → NTC 衝突
  (dsmc_ncand → dsmc_pairs) → サンプリング (dsmc_sample、ソート済みなのでセルごとに加算)。
- 移動と境界: 自由飛行 (軸対称は 3D 直線の子午面射影)、外周 4 辺の区間表 (壁・鏡面・リザーバ・
  真空。線分指定 p1-p2 は辺上の部分区間、後の指定が優先、軸は鏡面に強制) と固体 (導体・誘電体の
  円・多角形との厳密な交点、壁温の拡散反射) で最初の交点を求め、反射・再放出の後は残り時間を
  最大 6 レグまで飛行 (v1 と同じ)。固体の判定は始点・終点のセルが気体のみなら省く。
- NTC: セルごとの候補数 N_cand = ½N(N−1)W(σc_r)_max Δt/V + 端数 (dsmc_ncand) を排他的
  累積和にし、候補対ごとに 1 スレッド (dsmc_pairs)。分子の占有はステップ番号のスタンプへの
  atomicMax で取り、両方取れなかった候補は次のステップへ持ち越す (1 ステップに 1 分子 1 衝突 =
  v1 の重複除去と同じ)。(σc_r)_max は double のビット列への atomicMax で更新。
  (セルごとに 1 スレッドで順に処理する版は、セルが少なく混んでいると GPU が遊ぶので不採用:
  圧力駆動チャネルで衝突が 3 ms/step → 0.19 ms/step)
- 平滑化: 4 近傍の体積重み対称拡散 (θ = 0.2、総量保存・正値)。

## v1 との違い

固体は厳密形状で拡散反射 (v1: 導体はメッシュ境界の折れ線、誘電体は「移動を取り消して等方
Maxwell で再抽選」)。乱数は Philox で統計的に等価 (ビット一致しない)。threads は無視。
周期境界は未対応 (v1 も未対応)。

## 検証 (tests/test_v2_gdsmc.py、v1 と同じ条件)

| 項目 | 結果 |
|---|---|
| 平衡箱 (10 Pa, 300 K) | n/n0 = 1.000、T = 300.1 K、分子数保存 |
| 無衝突の流出 | 密度 0.4995 (理論 0.5)、u = 0.4965 c̄ (0.5)、流出/流入 = 1.000 |
| 圧力駆動チャネル (20 → 5 Pa) | 4 区間の圧力が v1 と 1.5% 以内、流速 72.8 m/s (v1 72.4) |
| 流量指定 10 sccm | 流入レートが換算値に 2% 以内、流入 = 流出 |
| 軸対称 | 密閉円筒の径方向の一様性 (内外 8% 以内)、無衝突円筒の流出 (密度 1/2・u = c̄/2) |
| 固体越しの流れ | 固体内に分子が入らない、質量収支 |
| 高温壁 (600 K / 300 K) | 温度が単調に分布 |
| 速度 (50×20 mm、16,000 セル、40 万分子、円柱障害物) | v1 (numba 8 スレッド) 42.2 ms/step → v2 1.2 ms/step (35 倍) |
